# Changelog

## 0.1.0 – 2026-11-21

First release.

- Read-only alarm panel with the alarm state and who last changed it
- Binary sensors, sensors and a read-only lock created from the features each device reports
- Real-time updates over WebSocket, with a full refresh every 5 minutes
- Automatic token renewal, re-login and re-authentication from the UI
- English and Norwegian (bokmål) translations
